# LegacyLift

Day 1 submission for the OpenAI x Outskill hackathon.

## Idea

LegacyLift will help developers modernize old codebases using OpenAI/ChatGPT. The planned workflow is:

- Upload legacy code.
- Generate plain-English documentation.
- Rewrite the code into a modern target language.
- Generate tests and a migration summary.
- Provide a simple report for review.

## Day 1 Progress

Today I started the project, finalized the idea, prepared the GitHub repository, documented the planned OpenAI-powered workflow, added safe `.gitignore` rules so API keys are not pushed, and created the Day 1 working document for submission.

## Current Status
